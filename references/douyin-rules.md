# 抖音平台口播审核规则要点

> 用途：口播文案发布前审核的平台规则依据。内容依据《抖音社区自律公约》、抖音创作者规则及平台公开审核口径整理，规则随平台政策更新，如发现与平台最新规则冲突，以平台最新公告为准。

## 一、通用红线（无论什么赛道都命中）

| 规则类别 | 平台口径 | 口播常见触发场景 |
|---|---|---|
| 违禁词/绝对化用语 | 禁止使用国家法规明令禁止的极限词与绝对化表述 | "最好/最强/第一/全网唯一/史无前例" |
| 虚假宣传 | 禁止发布无依据、无法证实的商品或服务功效、性能、销量、口碑信息 | "销量第一""效果立竿见影" |
| 医疗健康功效 | 非医疗机构的普通商品/内容不得声称疾病治疗、预防、诊断功能；保健品不得宣称治疗作用 | "治失眠""降血糖""消炎""抗癌" |
| 金融收益承诺 | 禁止宣传无风险高收益、保本保收益、稳赚不赔等金融投资承诺 | "稳赚""保本""翻倍""年化X%稳收" |
| 导流外链/引流 | 禁止在视频口播/评论区/私信引导用户脱离平台交易，或以加微信等话术引流 | "加微信""私信我领""某宝搜" |
| 诱导互动 | 禁止诱导点赞、关注、评论、转发等互动以获取抽奖/福利资格（无资质抽奖等） | "点赞抽奖""转发送""关注领" |
| 色情低俗 | 禁止低俗、性暗示、露骨内容 | 擦边文案、双关暗示 |
| 未成年人保护 | 禁止涉及未成年人色情、暴力、诱导不良行为 | 涉及未成年人的不当内容 |
| 版权侵权 | 未经授权使用他人版权音乐、视频、图片、文案 | 直接搬运他人口播稿、使用未授权BGM |
| 敏感事件/时政 | 不得借社会热点事件、公共事件进行不当解读、带节奏、传播不实信息；时政内容须合规表述 | 社会事件蹭热点定性、编造细节 |
| 地域/群体歧视 | 禁止地域黑、群体贬损、性别对立等歧视性内容 | "XX省人怎样""00后怎样"等绝对化群体表述 |

## 二、口播文案专项要点

1. **开头3秒**：抖音对前几秒做停留判定，口播开头避免直接抛敏感词或争议定性，易触发限流与举报。
2. **商品/品牌口播**：凡涉及商品功能、成分、效果、材质、产地、价格、促销政策，必须有据可查；禁用"官方没说过的功效"。
3. **对比类口播**：不得点名贬损同行/竞品（"XX车不行""买XX的亏了"），不得使用无出处的对比数据。
4. **价格与促销**：涉及价格、优惠、补贴、政策需与真实活动一致；"限时""最后一天""抢购"需真实存在促销背景，否则属虚假促销。
5. **评论区风险**：口播里引导评论区互动本身允许（自然引导），但"评论区领福利/留微信/加群"属违规引流。
6. **案例/用户证言**：不得编造用户身份、使用体验、收入、疗效；真实案例也需隐去可定位隐私信息。
7. **数据引用**：引用销量、市场份额、用户量、测试数据等须注明来源且来源真实可查。

## 三、审核时对不确定词的判断原则

- **无法证实 = 高风险**：任何"最、第一、唯一、绝对、100%、保证、必"类表述，除非平台规则明确豁免（如"本公司产品"自指），否则一律标红。
- **模糊语义不清 = 提示修改**：语义含混、可被解读为功效承诺或贬损的表述，即使不直接命中词库，也提示用户改写，降低被举报/限流风险。
- **行业通用豁免词**：如"最"在特定语境（如"我最喜欢"主观感受）不违规；审核时结合语境判断，主观感受类表述可从宽，客观宣称类从严。
